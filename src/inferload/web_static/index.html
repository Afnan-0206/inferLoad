Defensible LLM Capacity Measurement Semantics

InferLoad is an LLM inference capacity testing laboratory designed for defensible benchmarking under multi-concurrency load. Rather than relying on generic HTTP ping timing, InferLoad tracks client-observed streaming physics:

  • Time to First Token (TTFT): Client-observed time elapsed from HTTP request dispatch until receiving the first usable streamed content chunk. Reflects initial response delay and server-side queueing; client-side measurement alone does not isolate GPU memory pressure or internal prefill queue depth without correlated server telemetry.
  • Total Latency: End-to-end client-observed request duration across all generated tokens, tracking p50, p95, and p99 percentiles for tail latency behavior under concurrent load.
  • Throughput (tok/s & req/s): Client-observed token generation rate and completed request rate across concurrent streams, measuring overall generation capacity under load.
  • Error Rate %: Measures dropped requests, HTTP 429 backpressure, and timeout drops.
  • Highest Observed Compliant Tested Concurrency: The maximum tested concurrency level where all repetitions met your specified SLO thresholds. Concurrency levels with tail latency or error violations are flagged as non-compliant for the configured workload.

🎯 What InferLoad Measures

InferLoad is an LLM inference capacity testing laboratory designed for defensible benchmarking under multi-concurrency load. Rather than relying on generic HTTP request timing, InferLoad tracks client-observed streaming metrics:

  • Time to First Token (TTFT): Client-observed time elapsed from HTTP request dispatch until receiving the first usable streamed content chunk. Reflects initial response delay and server-side queueing; client-side measurement alone does not isolate GPU memory pressure or internal prefill queue depth without correlated server telemetry.
  • Total Latency: End-to-end client-observed request duration across all generated tokens, tracking p50, p95, and p99 percentiles for tail latency behavior under concurrent load.
  • Throughput (tok/s & req/s): Client-observed token generation rate and completed request rate across concurrent streams, measuring overall generation capacity under load.
  • Error Rate %: Measures dropped requests, HTTP 429 backpressure, and timeout drops.

🚦 Executive Capacity Planner & Strict SLO Gates

InferLoad determines the Highest Observed Compliant Tested Concurrency: the maximum tested concurrency level where all repetitions met your specified SLO thresholds (e.g. TTFT < 350ms, Latency < 1500ms, Error < 1.0%). Concurrency levels with tail latency or error violations are flagged as non-compliant for the configured workload.
