InferLoad Observability Guide

🎯 What InferLoad Measures

InferLoad is a rigorous, SRE-grade LLM inference capacity testing laboratory. Unlike generic HTTP load testers, InferLoad captures token-level streaming physics:

  • Time to First Token (TTFT): Time elapsed between HTTP request dispatch and receiving the initial token chunk. Directly indicates prefill queue depth and GPU memory pressure.
  • Total Latency: End-to-end elapsed time across all generated tokens. Measures tail degradation across worker pools.
  • Throughput (tok/s & req/s): Output generation rate. Evaluates KV-cache scheduling efficiency and tensor-parallel saturation.
  • Error Rate %: Measures dropped requests, HTTP 429 backpressure, and model context timeouts.

🚦 Executive Capacity Planner & Strict SLO Gates

InferLoad calculates the Highest Observed Compliant Tested Concurrency against your defined SLO thresholds (e.g. TTFT < 350ms, Latency < 1500ms, Error < 1.0%). Any concurrency level that triggers a tail violation is classified as unfeasible for production deployment.
